# YOM's Security Policy

## Supported Versions

The latest version is the supported version, if a vulnerability is found, it will be fixed in the next patch or minor
update.

## Reporting a Vulnerability

If you find a vulnerability, please submit it privatly via GitHub Security Advisories; if that is not possible, please E-mail G0o53 at `G0o53@protonmail.com` 
we expect it to have a clear explanation on what the vulnerabilty is, if possible, a minimal reproduction would be greatly appreciated.
We will get to the vulnerability as soon as we can. As soon as it is patched, it will be posted about

## How Fast Will it be Patched?
We aim to acknowledge reports within a few days and patch critical issues as soon as possible.
Please avoid publicly disclosing vulnerabilities until a fix is released.

## Reporting a Bug

If you find a bug, please open a issue with the tag `bug`, and provide a clear explanation on what it is and how to reproduce it; if you can write a PR
to fix it, that would be greatly appreciated.
